CLAIMS TO AUDIT

1. First-difference labels. For any orientation of a tournament whose vertices
are distinct h-digit base-q words, label x->y by
  (u-1)(q-1) + x_u - 1{x_u>y_u},
where u is their first differing position. A set is head-coherent when all
arcs entering each fixed head within the set have the same label. The claim
is that every such set has size at most h+2, sharp for q>=3 over arbitrary
orientations. Check fixed-head injectivity, the bucket induction, binary and
mixed-radix edge cases, and the sharpness example. Global label injectivity
or a proper walk coloring is not assumed.

2. Exact construction. For q>=3 set r=13(q-1), M=r^2, k=2M^2+1. Orient i->j
when 1 <= (j-i) mod k <= M^2 and use thirteen base-q digits. Verify capacity,
regularity, the exact no-coherent-16 source contract, and the claimed uniform
O(log^2 M) bit time/O(log M) storage per query without witness advice.

3. Coupled profiles. Reconstruct the inherited nested Boolean predicates and
the definitions of the ordinary/joint profiles. With child profiles
(a,b,c,e)=(S0,S1,J0,J1), the proposed zero-side bounds are
  F0=max(a+14c, a+13c+b, 15c+e, 13c+b+e, 14c+2e, 12c+3e),
  FJ=max(a+14c, a+13c+e, 15c+e, 14c+2e, 12c+3e).
The one-side bounds remain M^2*a+r*b and M^2*c+r*b. Check every candidate
case, repair-coordinate overlaps, the exceptional head-label reassignment,
and especially the argument for two distinct parent indices. Separate a
proof for arbitrary nested child predicates from tests of small abstractions.
Check base profiles, terminal joint-profile conventions, monotone propagation,
common disjoint zero-block witnesses, OR balancing, and composition.
